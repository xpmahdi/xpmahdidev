Philosophy & Approach

Why "The Normal One"?

In an ecosystem cluttered with hype-driven complexity and fragile abstractions, I prioritize the bedrock: rock-solid Linux fundamentals, reproducible containers, and automated delivery pipelines.

Reproducible Infrastructure

Eliminating "it worked on my machine". Services are packaged in multi-stage Docker images, orchestrated with Compose or k3s, and backed by persistent storage volumes.

Automated CI/CD & Resilience

Manual deployments don't scale. I build automated GitHub Actions workflows for linting, testing, and image builds alongside HAProxy/Nginx load balancing for high availability.

Proactive Observability

You can't fix what you can't see. Real-time metric scraping with Prometheus, visual Grafana dashboards, and PromQL alert rules detect bottlenecks before downtime happens.

Inspect Production Configs & Pipelines

Switch between a Multi-Stage Dockerfile, Kubernetes StatefulSet, and GitHub Actions CI Workflow:

# Dockerfile - Hardened Multi-Stage Production Build (-60% Image Size)
FROM python:3.12-slim AS builder
WORKDIR /build
COPY requirements.txt .
RUN pip wheel --no-cache-dir --no-deps --wheel-dir /build/wheels -r requirements.txt

FROM python:3.12-slim AS runtime
RUN useradd --create-home --shell /bin/bash appuser
WORKDIR /app
COPY --from=builder /build/wheels /wheels
RUN pip install --no-cache /wheels/* && rm -rf /wheels
COPY --chown=appuser:appuser . .

USER appuser
EXPOSE 8000
HEALTHCHECK --interval=30s --timeout=3s CMD curl -f http://localhost:8000/healthz || exit 1
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
